Projects

Home server with Linux and Docker

My own server on a small HP computer running Ubuntu Server. It streams films and series to phones and TVs, both at home and on the go.

  • All services run as Docker containers, defined in a single Docker Compose file.
  • The Jellyfin media server uses hardware acceleration to transcode video.
  • Part of the traffic is routed through a WireGuard VPN in its own container, so nothing can leak outside the tunnel.
  • Secure remote access through Tailscale, without opening any ports on the router.
